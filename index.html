云上笔记

把想法，安放在云端

一个简洁、轻量的云端笔记工具。支持 Markdown 编辑、实时同步、图片墙、留言板，你的笔记安全存储在云端，多端随时访问。

已有账号？点击「立即开始」登录

核心功能

Markdown 编辑

支持标题、加粗、列表、引用、代码、图片链接等常用语法，编辑/预览一键切换，自动保存。

实时同步

连接 Supabase 后，笔记通过实时通道在多个设备间自动同步，手机电脑无缝衔接。

图片墙

自动从所有笔记正文中聚合图片，点击可放大查看，让你的灵感和素材一目了然。

留言板

公开留言区域，任何人都可以留下建议或反馈，与站长和其他用户互动交流。

数据安全

笔记按用户隔离，通过数据库行级安全策略保护，只有你本人能访问自己的笔记内容。

暗色模式

支持浅色/深色主题一键切换，选择后自动记住偏好，夜间写作也能护眼舒适。

Supabase 连接

在 Supabase 控制台创建项目后，将「项目设置 → API」中的 Project URL 与 anon public key 填入下方。

首次使用指引

连接前，请先在 Supabase 中创建数据表。点击右侧按钮复制 SQL，在 Supabase 的 SQL Editor 中执行即可。

笔记数据按用户隔离：登录后只能看到自己的笔记。留言板为公开区域，无需登录即可浏览和留言。
